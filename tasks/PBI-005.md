# PBI-005: Keystatic Collections — Labs, Research, Experiments, Projects

## Directive
Define the first half of the relationship-first content model in `keystatic.config.ts`. Configure collections `labs`, `research`, `experiments`, `projects` with fields: identity (`title`, `slug` (generated from title, editable, stable), `description`, `status`), publishing (`published: boolean`, `publishedAt`, `updatedAt`), relationships (Lab→research/experiments/projects/articles/people/organizations/technologies; Research→lab/experiments/projects/articles; Experiment→lab/research[]/project?/articles with outcome VALIDATED/INCONCLUSIVE/FAILED/PARTIAL; Project→originLab?/research/experiments/articles/people/organizations/openSource with type Internal/Client/Startup/Collaboration/Open Source/Research and stage Idea→…→Live→Completed/Spun Out/Archived), metadata (`featured`, `priority`, `tags`), SEO (`seoTitle`, `seoDescription`, `socialImage`), and image fields requiring `alt`. Use `storage: local` for dev (switch to `github` via env in production). Create `src/content/{labs,research,experiments,projects}/` directories with `.gitkeep` + two sample fixtures (one `published`, one `draft`) per collection to prove publishing lifecycle. No data access helpers yet (next PBI).
