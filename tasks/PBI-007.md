# PBI-007: Centralized Data Access Layer (src/lib/content)

## Directive
Centralize all content querying behind a single layer so pages never import `astro:content` or Keystatic directly. Create `src/lib/content/{labs.ts, research.ts, experiments.ts, projects.ts, articles.ts, people.ts, organizations.ts, opensource.ts, roadmap.ts, relationships.ts}` exposing at minimum `getLabs()`, `getActiveLabs()`, `getLabBySlug(slug)`, `getProjects()`, `getProjectsByLab(labSlug)`, `getResearchByLab(labSlug)`, `getExperimentsByResearch(researchSlug)`, `getArticlesByLab(labSlug)`, `getPeopleByLab`, `getOrganizationsByLab`, plus generic `getRelatedLabs/Research/Experiments/Projects/Articles` helpers that walk the relationship graph. Every helper must filter to `published === true` by default and accept an explicit `includeDrafts` opt-in. Add `src/lib/content/index.ts` barrel and a helper `getReadingTime(markdown)` for articles. Do not build pages or change schemas — consume `PBI-005/006` fixtures only.
