# PBI-016: Participate Cluster — Sponsorship, Collaboration, Contact Form

## Directive
Implement the participation gateway (spec §61/§62) via Astro prerendered pages + a validated server form. Create `src/pages/participate/index.astro` (hub linking to all three), `src/pages/participate/sponsorship/index.astro` (singleton `pages/sponsorship` — positioning "Support independent technology research and experimentation.", tiers Research Supporter/Lab Sponsor/Project Sponsor/Technology Partner/Strategic Partner, what support enables), `src/pages/participate/collaboration/index.astro` (types Research/Technology/Project/Startup/Open-source/Sponsorship), and `src/pages/contact/index.astro`. Build shared form component `src/components/astro/ContactForm.astro` + API route `src/pages/api/contact.ts` (Astro `APIRoute`, `prerender=false`, Zod-style validation for `name`/`organization`/`email`/`interest`/`message`, honeypot field, rate-limit hook abstraction, preserves input on error, success confirmation page, JS-disabled full POST fallback, no secrets in client bundle). Reuse the same endpoint for both collaboration and contact forms.
