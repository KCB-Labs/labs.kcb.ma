# PBI-017: Build-time Search Index + Search Island

## Directive
Add discoverability without backend search. Create `src/lib/search/buildIndex.ts` that walks `published` Labs/Projects/Articles/Research/Experiments/People/OpenSource via `src/lib/content` helpers and emits a JSON index (`public/search-index.json` or `dist/search-index.json` via `src/pages/api/search.json.ts` / static build hook) with entries `{type, title, slug, description, href, tags?}`. Build React island `src/components/react/Search.tsx` (`client:visible`) with accessible combobox (input, debounced query, result list with `type` badge LAB/PROJECT/ARTICLE etc., keyboard ArrowUp/Down + Enter, Escape close, `aria-live` result count), and mount it in `SiteHeader` + on `/search` or as header dropdown. Ensure index is generated at build time, not fetched from CMS at runtime, and analytics hook `track('search', query)` goes through the abstracted analytics adapter.
