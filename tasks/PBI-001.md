# PBI-001: Scaffold Astro + TypeScript + React + Keystatic + Node Adapter

## Directive
Scaffold the production-ready Astro shell with strict TypeScript and server output. Install and configure `astro`, `@astrojs/react`, `@astrojs/markdoc`, `react`, `react-dom`, `@keystatic/astro`/`@keystatic/core`, and `@astrojs/node` (standalone). Create `astro.config.ts` with `output: 'server'`, `adapter: node({mode:'standalone'})`, `integrations: [react(), markdoc(), keystatic()]`, `site: 'https://labs.kcb.ma'`, update `package.json` scripts to `astro check` + `tsc --noEmit` for `check` and `astro build` for `build`, update `tsconfig.json` for Astro, and verify via Astro MCP that APIs match installed versions. Do not add content collections, styles, or pages beyond the minimal Astro skeleton (`src/pages/index.astro` placeholder with `export const prerender = true` proof). Must pass `check` and `build` on the empty scaffold.
