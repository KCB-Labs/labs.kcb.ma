# PBI-010: Labs Index + Lab Detail (Research Portal)

## Directive
Implement the Lab discovery surface as a research portal (spec §18). Create `src/pages/labs/index.astro` (prerendered list of published labs via `getLabs()` with `LabCard` each, sorted `featured` then `priority`) and `src/pages/labs/[slug].astro` (`export const prerender = true` + `getStaticPaths` from `getLabs()`, each path validated, unknown slug → branded 404). Lab detail renders via `LabLayout.astro` or composed Astro components: breadcrumb, label/title/description/status, Overview, Why we're exploring, Research (ResearchCards from `getResearchByLab`), Experiments (ExperimentCards), Projects born from this Lab (`getProjectsByLab`), People (`PersonCard`), Collaborators (OrganizationCard), Technologies (tags), Related Journal (`getArticlesByLab`), Timeline. All sections render empty-state gracefully when relation is empty. Share `LabCard`/`ResearchCard`/`ExperimentCard`/`ProjectCard`/`ArticleCard`/`PersonCard`/`OrganizationCard` and `Timeline` stub. No React islands in this PBI.
