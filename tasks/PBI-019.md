# PBI-019: Related Discovery + Interactive Timeline (Knowledge Graph Hook)

## Directive
Close the relationship traversal loop with editorial-quality related sections and a minimal interactive timeline. Ensure every detail page's related blocks (Lab/Project/Experiment/Research/Article) render via `src/lib/content/relationships.ts` helpers (no invented IDs, published-only, empty-state safe). Build/upgrade `src/components/react/Timeline.tsx` as a `client:visible` island for Lab/Project detail and `Roadmap` page (chronological sort, keyboard navigable, respects `prefers-reduced-motion`, no continuous motion/parallax/large animated backgrounds per §35), and expose the full relationship graph shape via a data helper (`getKnowledgeGraphData()`) that a future visualization can consume — but do not ship a full graph visualization in this PBI unless it is trivial and an ADR justifies any new library (spec §74 marks graph as future layer).
