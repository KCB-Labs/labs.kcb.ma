# PBI-002: Design Tokens & Global Styles (Light/Dark)

## Directive
Establish the design system token layer that all subsequent components must consume. Create `src/styles/tokens.css` defining CSS custom properties for colors (`--color-bg`, `--color-surface`, `--color-text`, `--color-muted`, `--color-accent`, `--border-subtle`), typography (`--font-display`, `--font-body`, `--font-mono`, scales for Display/H1/H2/H3/Body/Small/Metadata/Code), spacing (`--space-1`…`--space-8`), radius (`--radius-sm/md/lg`), borders, shadows, motion (`--motion-ease`, `--motion-duration`), containers, breakpoints, and z-index per spec §33. Add `src/styles/globals.css` (reset, typography hierarchy, focus styles, `prefers-reduced-motion` baseline) and wire both into layouts. Support light/dark theme via token overrides (e.g., `[data-theme]` or `prefers-color-scheme`) without scattering literal values. Do not build cards, layouts, or pages beyond importing the tokens.
