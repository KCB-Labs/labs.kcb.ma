# PBI-003: Core Layouts & Navigation (BaseLayout, Header, Footer, Container)

## Directive
Build the reusable Astro-only shell that every public page will inherit. Create `src/layouts/BaseLayout.astro` (html/head with `title`, `description`, `canonical` (absolute via `Astro.site`), OG/Twitter/Schema.org slots, `tokens.css`/`globals.css` imports, `ViewTransitions` if appropriate), `src/components/astro/SiteHeader.astro` + `SiteFooter.astro` (compact IA: KCB Labs / Explore{labs,projects,open-source} / Journal / About{vision,people,ecosystem,roadmap} / Participate{sponsorship,collaboration,contact} + Search entry), `src/components/astro/Container.astro` + `Section.astro` + `Breadcrumbs.astro` + `PageHeader.astro` + `Prose.astro`. All components must be Astro (no `client:*` directives) and consume tokens only. Layouts must support `prerender` per page and pass heading/landmark structure checks. Wire `src/pages/index.astro` to use `BaseLayout` end-to-end as proof.
