# ADR-001: Astro output: server + @astrojs/node standalone

## Status

Accepted (2026-08-27)

## Context

KCB Labs website needs server-side rendering for Keystatic admin (`/keystatic`) which requires Node.js APIs. Public content pages should be prerendered for performance. The site deploys to Coolify via Docker.

## Decision

Use Astro with `output: server` and `@astrojs/node` adapter in `mode: standalone`. Public routes use `export const prerender = true` for static generation. `/keystatic` and `/api/*` remain dynamic.

## Alternatives

- **Static only (`output: static`):** Rejected — Keystatic needs server runtime.
- **`output: server` with Node adapter `mode: middleware`:** Rejected — standalone is simpler for Docker deployment.
- **Other adapters (Vercel, Netlify):** Rejected — self-hosted on Coolify.

## Consequences

- Keystatic admin works with GitHub OAuth in production
- Public pages are prerendered for performance
- Docker image runs `node ./dist/server/entry.mjs`
- Must keep `@astrojs/node` adapter installed
