# ADR-005: Avionics Design System Adoption

## Status
Accepted

## Context
KCB Labs website needed a distinctive, authoritative visual identity that avoids the generic SaaS/agency aesthetic. The ASDLC Avionics Design System provides a "Timeless Industrial" palette rooted in aerospace flight manuals and Dieter Rams' Braun designs — aligning with KCB's identity as a rigorous R&D platform.

## Decision
Adopt the ASDLC Avionics Design System for KCB Labs:
- **Colors:** International Safety palette (#f4f4f0 bg, #ebebe6 surface, #111111 text, #f04e30 Safety Orange accent)
- **Typography:** Archivo (headings/body) + B612 Mono (Airbus cockpit monospace)
- **Headings:** Uppercase, expanded width (wdth 110), 700 weight
- **Layout:** 6-column CSS Grid with named zones (full, breakout, content at 67ch)
- **Components:** Border-box cards, industrial square badges, monospace metadata
- **Branding:** KCB logo image in header, favicon from docs/branding/

## Consequences
- All tokens replaced in `src/styles/tokens.css`
- All components updated to use Avionics tokens
- Google Fonts loaded for Archivo + B612 Mono
- Dark theme preserved with warm dark palette
- No content changes required — purely visual/systemic

## Alternatives considered
- Keep existing cool-slate palette (rejected: too corporate/generic)
- Custom design system from scratch (rejected: Avionics is well-documented and proven)
